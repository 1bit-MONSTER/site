1bit.gg: the 1bit engine site#

This repository builds https://1bit.gg/, the site of the 1bit engine: local LLM inference on the AMD Ryzen AI MAX+ 395 (Strix Halo) inside AMD's Lemonade Server, on the Radeon 8060S iGPU through HRX and on the XDNA 2 NPU.

  • tools/site.py renders the engine's README.md and docs/*.md (checked out from 1bit-MONSTER/engine) and this repository's blog/*.md with site/template.html, site/style.css and site/theme.js.
  • .github/workflows/pages.yml builds the site on every pull request, deploys main to GitHub Pages, and rebuilds every three hours so engine doc changes reach the site.
  • Every page carries its canonical address, Open Graph and Twitter card tags and JSON-LD; the build writes sitemap.xml (lastmod from git), robots.txt and the Atom feed feed.xml.

Build locally:

python3 -m pip install markdown==3.10.3
git clone https://github.com/1bit-MONSTER/engine ../engine
ONEBIT_ENGINE_DIR=../engine python3 tools/site.py _site
